Tipos de Señales de Interfaz

Clasificación de señales según su naturaleza física y digital

📥 Señales de Entrada (Sensores)
  • Digitales (DI - Todo/Nada): Estados booleanos (0/1): pulsadores, finales de carrera, detectores de presencia.
  • Analógicas (ADC / A/D): Magnitudes continuas (tensión/corriente) convertidas a enteros de n bits.
  • Contadores / Pulsos: Captura de impulsos mediante encoders ópticos para medir velocidad y posición.
  • Numéricas (Buses E/S): Tramas de datos por protocolos serie (SPI, I²C, CAN, RS-232/485).
📤 Señales de Salida (Accionadores)
  • Digitales (DO - Todo/Nada): Elementos binarios de potencia: relés, contactores, electroválvulas, LEDs.
  • Analógicas (DAC / D/A): Números enteros convertidos a tensión/corriente para graduar potencia.
  • Modulación PWM: Variación del ciclo de trabajo (Duty Cycle) para generar una acción analógica equivalente.
  • Comandos Numéricos: Envío de datos digitales hacia variadores de frecuencia o actuadores inteligentes.

Acondicionamiento de Señal y Potencia

La CPU opera en un entorno digital de baja potencia (órden del mW o pocos voltios), mientras que los procesos industriales manejan altas tensiones y corrientes:

Adaptación en Entradas (Sensores) • Filtrado: Elimina ruido eléctrico e interferencias de alta frecuencia.
• Amplificación / Atenuación: Adapta el rango físico (ej. ±100 mV de un termopar) al rango del ADC (0 … 5 V).
• Aislamiento Galvánico: Uso de optoacopladores para proteger la CPU de sobretensiones.
Etapa de Potencia en Salidas (Actuadores) • Amplificación de Corriente: Un pin de microcontrolador suministra ~20 mA; un relé o motor requiere de varios Amperios.
• Drivers y Relés: Conmutación con transistores (MOSFET), relés electromecánicos o relés de estado sólido (SSR).
• Conversión de Energía: Modulación de fuentes externas de 24 V, 230 V o 400 V.

Diferencia clave: Cada bit de cada dirección en el mapa de E/S está físicamente conectado a una patilla (pin) o circuito exterior.

Entradas Digitales (DI): Estado Todo/Nada

Funcionamiento de una Entrada Digital

Evalúa si la tensión en el pin está por debajo del umbral de '0' (ej. < 0.8 V) o por encima del umbral de '1' (ej. > 2.4 V).

  • Contactos Normalmente Abiertos (NO): Devuelven 0 en reposo y 1 al ser pulsados.
  • Contactos Normalmente Cerrados (NC): Usados en setas de emergencia por seguridad (devuelven 1 en reposo).
Lectura de un Pin Digital en C 

// Ejemplo: Control de inicio de ciclo
int marcha = LeerPinDigital(PIN_BOTON_START);

if (marcha == 1) {
    IniciarProceso();
} else {
    EsperarOperador();
}

Salidas Digitales (DO): Actuación Binaria

Gobierno de Cargas Todo/Nada

El software escribe un valor '0' o '1' en un registro de salida para activar un interruptor de estado sólido o electromecánico.

  • Relés Electromecánicos: Aislamiento total, pero conmutación lenta (> 10 ms) y desgaste mecánico.
  • Transistores / SSR: Conmutación electrónica ultra-rápida (soplado de válvulas, control directo).
Escritura de Salida Digital en C 

// Ejemplo: Control de Bomba de Calefacción
if (temperatura_actual < TEMP_CONSIGNA) {
    EscribirPinDigital(PIN_RELE_BOMBA, 1); // Encender
} else {
    EscribirPinDigital(PIN_RELE_BOMBA, 0); // Apagar
}

Operaciones Bitwise sobre Puertos Digitales

▫ Operaciones con el bit de peso P de la variable entera X:
Para operar sobre un solo bit sin alterar el resto, creamos una mascara = 1 << P (desplaza el bit 1 P posiciones a la izquierda, generando el binario con solo ese bit activo).

Operación sobre el bit P Sintaxis en C (Variable X) Lógica de Control Industrial
¿Está activo el bit de peso P? if (X & mascara) Consultar estado de un sensor o pulsador.
Poner a 1 el bit de peso P X = X | mascara; Activar un relé, válvula o motor.
Poner a 0 el bit de peso P X = X & ~mascara; Desactivar una salida o limpiar alarma.
Cambiar/Invertir el bit P (Toggle) X = X ^ mascara; Bascular el estado (ej. parpadeo de LED).

Entradas Analógicas: Conversor A/D (ADC)

Cuantificación y Resolución del ADC

Mide una tensión continua y la divide en 2n niveles enteros:

  • ADC 10 bits: 210 = 1024 niveles (cuentas de 0 a 1023).
  • ADC 12 bits: 212 = 4096 niveles (cuentas de 0 a 4095).
  • Paso de resolución: ΔV = (Vref+ − Vref−) / (2n − 1).
Escalado Físico en C (Termopar) 

// Lectura de ADC de 10 bits (0..1023)
int ad_k = LeerADC(CANAL_TERMOPAR);

// 1. Convertir cuentas del ADC a voltios
float Vad_k = ad_k * (5.0f / 1023.0f);

// 2. Deshacer la amplificación x500 previa
float Vhc_k = Vad_k / 500.0f;

// 3. Convertir voltios a grados Celsius
float temp_c = Vhc_k / SENSIBILIDAD_TERMOPAR;

Salidas Analógicas: Conversor D/A (DAC)

Generación de Tensiones Continuas

Convierte el valor entero calculado en C a un nivel proporcional de tensión para mandar a un variador de velocidad o válvula proporcional.

  • DAC 8 bits: Cuentas de 0 a 255.
  • Rangos industriales estándar: 0 … 10 V, ±10 V o bucle de corriente 4 … 20 mA.
Cálculo de Salida DAC en C (Electroválvula) 

// Apertura deseada en porcentaje (0.0% a 100.0%)
float apertura_pct = 75.0f;

// Tensión deseada en la válvula (0 a 24V)
float Vvalvula = (apertura_pct / 100.0f) * 24.0f;

// Tensión enviada al DAC de 8 bits (atenuada x5)
float Vdac = Vvalvula / 5.0f;
int da_k = (int)(Vdac / 5.0f * 255.0f);

EscribirDAC(da_k);

Periféricos de Movimiento: Encoders y PWM

Entrada Contador (Encoder incremental)

Cuenta transiciones de pulsos. Con señales A y B desfasadas 90° (cuadratura), el hardware detecta el sentido de giro. 


int count_k = LeerContadorEncoder();
float pos_deg = count_k * (360.0f / PULSOS_REV);
Salida PWM (Pulse Width Modulation)

Simula una tensión analógica conmutando una señal digital a frecuencia fija. Varía el Duty Cycle (TON / TPWM). 


float duty_k = Vcontrol / Vmax; // Rango 0.0 a 1.0
float Ton_k  = duty_k * Tpwm;
EscribirPWM(Ton_k);

Periféricos Inteligentes y Buses Numéricos

Los sensores y actuadores industriales modernos sustituyen las líneas analógicas simples por **buses de comunicación digital serie**:

Buses y Protocolos Frecuentes: • En placa / Corta distancia: I²C (2 hilos), SPI (4 hilos).
• Industriales y automoción: CAN bus, RS-485, Modbus RTU.
• Serie Estándar y Redes: RS-232, USB, Ethernet industrial (PROFINET, EtherCAT).
Estructura del Programa en C: 1. Inicializar el periférico controlador (Init_I2C()).
2. Formatear la trama enviando la dirección del dispositivo esclavo.
3. Leer/escribir paquetes de bytes procesándolos mediante librerías o drivers.

Buenas Prácticas de Programación de E/S

  1. Uso de #define para constantes de hardware: Declarar siempre las resoluciones de bits, ganancias, voltajes de alimentación y direcciones de puertos mediante constantes para evitar "números mágicos".
  2. Abstracción mediante Funciones Limpias: Encapsular el acceso al hardware en funciones legibles. El algoritmo de control debe llamar a float LeerTemperatura() o void ActivarMotor(float V) en lugar de manipular los registros directamente en el main().
  3. Atención a los Tipos de Datos: Evitar la trampa de la división entera al convertir lecturas del ADC a voltajes reales (forzar operaciones con decimales añadiendo la extensión .0f).
