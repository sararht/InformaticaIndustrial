El Control de Procesos por Computador

Interacción en Tiempo Real con el entorno físico

1. Sensores (Entradas)

Miden las variables físicas del sistema (temperatura, posición, presión).

2. Computador / MCU

Ejecuta el programa de control en C y procesa la información en tiempo real.

3. Accionadores (Salidas)

Modifican el estado del sistema (motores, válvulas, relés, calefacción).

Ejemplo: Control de Temperatura

Bucle continuo de lectura, decisión y actuación


// Bucle principal de control en tiempo real
while (1) {
    float temp = leerSensorTemperatura();

    if (temp > 20.5) {
        activarCalefaccion(0); // Apagar
    } else if (temp < 19.0) {
        activarCalefaccion(1); // Encender
    }

    sleep_ms(5000); // Espera del ciclo de muestreo
}
