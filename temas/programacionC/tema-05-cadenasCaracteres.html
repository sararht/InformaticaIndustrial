Codificación de texto

Al igual que otros conceptos numéricos, el texto se codifica internamente como valores enteros:

  • Codificación estándar: Los computadores utilizan estándares comunes como ASCII y UNICODE.
  • ASCII: Utiliza 8 bits (1 byte) = 256 caracteres diferentes.
  • UNICODE: Utiliza 16 bits = 65.536 caracteres diferentes.
  • Tipo char: Almacena el número entero correspondiente al código binario del carácter.
  • Constantes de carácter: Se encierran entre comillas simples (ej. 'a' ≡ 97, '0' ≡ 48, '\n' ≡ 10).

Interpretación del tipo char

La variable char letra = 'a'; se almacena en memoria como el byte binario 01100001:

Valor Entero 97 1·26 + 1·25 + 1·20
Carácter 'a' Representación gráfica 

char c1 = 'a';
char c2 = c1 + 2; // Operación aritmética: 97 + 2 = 99 ('c')

if (c2 >= 'a' && c2 <= 'z') {
    printf("El carácter '%c' es una letra minúscula\n", c2); // Muestra 'c'
}

Cadenas de Caracteres (Strings)

Un texto en C es un **array de tipo char**.

Para no requerir una segunda variable con la longitud, las cadenas finalizan obligatoriamente con el carácter especial **nulo** (código 0 o '\0').

Estructura en memoria para char txt[5] = "Hola";:

txt[0]'H'
txt[1]'o'
txt[2]'l'
txt[3]'a'
txt[4]\0 (0)

¡Atención! Para almacenar una cadena de $N$ caracteres se debe declarar un array de al menos $N+1$ elementos.

Inicialización y Asignación


// Correcto: Inicialización en declaración
char txt[5] = "Hola";

// INCORRECTO: Asignación directa
char nom[5];
nom = "Pepe"; // Error: equivale a copiar direcciones

// INCORRECTO: Copia de arrays
nom = txt;   // Error de compilación
Constante String ("...") Devuelve un const char* con la dirección inicial del texto.
Nombre del Array Es una dirección constante; no se puede modificar mediante el operador =.

Operaciones Manuales con Strings

Toda operación sobre una cadena requiere recorrer el array elemento a elemento hasta encontrar el carácter 0:


char txt[5] = "Pepe";
char nom[5];
int i, iguales = 1;

// Copiar txt en nom
for (i = 0; txt[i] != '\0'; i++) {
    nom[i] = txt[i];
}
nom[i] = '\0'; // Asignar el carácter de cierre

// Comparar cadenas (no usar nom == txt)
for (i = 0; txt[i] != '\0'; i++) {
    if (txt[i] != nom[i]) {
        iguales = 0;
        break;
    }
}

Entrada / Salida de Cadenas

Funciones básicas para interactuar con texto por consola:

  • gets(cad); / puts(cad); Lectura y escritura rápida de cadenas.
  • scanf("%s", cad); Lee texto hasta el primer espacio en blanco.
  • printf("%s", cad); Muestra el contenido apuntado por la cadena.

char nombre[20], apellido[20];

printf("Nombre: ");
gets(nombre);
printf("Apellido: ");
gets(apellido);

printf("Nombre completo: %s %s\n", nombre, apellido);

Librería <string.h>: Gestión de Cadenas

strlen(cad) Devuelve el número de caracteres (sin contar el \0 final).
strcpy(dst, src) Copia el contenido de la cadena src en dst.
strcat(dst, src) Concatena (añade) la cadena src al final de dst.
strcmp(s1, s2) Compara alfabéticamente. Devuelve 0 si son iguales, <0 si s1 < s2, y >0 si s1 > s2.

Búsqueda y Variantes con Límite $N$

  • strncpy(dst, src, n) / strncat(dst, src, n) / strncmp(s1, s2, n): Operan limitando la acción a un máximo de $n$ caracteres.
  • strchr(str, c): Busca la primera aparición del carácter c en str (devuelve un puntero).
  • strstr(str, substr): Busca la primera ocurrencia de la subcadena substr dentro de str.

#include <stdio.h>
#include <string.h>
#include <stdlib.h>

char nombre[20] = "Marie", apellido[20] = "Curie";
char* todo = (char*) malloc(strlen(nombre) + strlen(apellido) + 2);

strcpy(todo, nombre);
strcat(todo, " ");
strcat(todo, apellido);

if (strcmp(todo, "Marie Curie") == 0) {
    puts("Es una científica notable.\n");
}
free(todo);

Conversión entre Texto y Números

Funciones para transformar numéricos a texto y viceversa:

  • atoi(cad) / atof(cad): Convierte una cadena a entero (int) o real (double).
  • sscanf(cad, fmt, ...): Extrae datos formateados desde un string exactamente igual que scanf.
  • sprintf(cad, fmt, ...): Escribe datos formateados dentro de una cadena de caracteres.

char texto[40] = "POS = 90";
int posicion;
char* cmd = strstr(texto, "POS");

if (cmd != NULL) {
    cmd = strchr(cmd, '=');
    if (cmd != NULL) {
        posicion = atoi(cmd + 1); // Extrae el número 90
    }
}

Buenas Prácticas con Cadenas

  • Espacio suficiente: Asegurarse de que el array de destino tiene capacidad para el texto concatenado más el nulo final. 
    
char txt[5] = "Pepe";
strcat(txt, " Pérez"); // ¡ERROR! Desbordamiento de memoria (Buffer Overflow)
  • Siempre finalizar con \0: Si se modifica manualmente un array de caracteres, garantizar la presencia del código 0 al final.
  • Memoria dinámica: Usar malloc para cadenas de tamaño desconocido o muy variable.

Resumen del Tema

  1. El tipo char representa un byte entero que codifica caracteres en ASCII.
  2. Un string es un array de caracteres delimitado por el carácter nulo \0.
  3. Las asignaciones y comparaciones de texto deben realizarse mediante funciones de <string.h>.
  4. sprintf y sscanf ofrecen un control potente para formatear y extraer datos de cadenas.
  5. Prevenir siempre el desbordamiento reservando tamaño suficiente en los arrays.
