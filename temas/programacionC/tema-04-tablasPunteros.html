Tablas (Arrays)

En muchas ocasiones necesitamos manejar conjuntos de variables del mismo tipo.

  • Variables sueltas: Requieren nombres distintos y hacen que el código sea tedioso e inabordable para grandes volúmenes de datos.
  • Tablas (Arrays): Agrupan elementos bajo un mismo nombre. El código mediante bucles se mantiene idéntico independientemente del tamaño.

// Variables sueltas
int x1, x2, x3, x4;
int media = (x1 + x2 + x3 + x4) / 4;

// Con arrays
int x[4], suma = 0, media, i;
for (i = 0; i < 4; i++) {
    suma += x[i];
}
media = suma / 4;

Manejo de Arrays en C

Al declarar tipo tabla[N]; en C:

  • N debe ser un valor constante conocido en compilación.
  • Se reservan en memoria N posiciones consecutivas del tipo indicado.
  • Los elementos se acceden desde el índice 0 hasta N-1 mediante tabla[i].
  • Importante: El identificador tabla a secas es una constante que almacena la **dirección de memoria inicial**.
  • C no comprueba si se sobrepasan los límites del array; es responsabilidad del programador.

Uso de Arrays con #define

Es buena práctica definir el tamaño mediante constantes simbolicás:


#define DIAS_ANYO 365

int nacimientos[DIAS_ANYO];
int defunciones[DIAS_ANYO];
int crec_anual = 0, i;

// Patrón típico en C: iniciar en 0 e iterar mientras i < TAMAÑO
for (i = 0; i < DIAS_ANYO; i++) {
    crec_anual += (nacimientos[i] - defunciones[i]);
}

Punteros (Pointers)

Un **puntero** es un tipo de dato que contiene la **dirección de memoria** donde se encuentra una variable.

  • Tipo de dato: tipo*.
  • Operador de dirección (&): Devuelve la dirección de memoria de una variable.
  • Operador de indirección o desreferencia (*): Permite acceder al contenido almacenado en la dirección que contiene el puntero.

int x = 5, y = 27;
int* pt;    // Puntero a entero

pt = &x;    // 'pt' almacena la dirección de 'x'
*pt = 44;   // Modifica el contenido de 'x' a 44
pt = &y;    // 'pt' ahora apunta a 'y'
*pt = 44;   // Modifica el contenido de 'y' a 44

Acceso Indirecto a Memoria

Estado de la memoria tras asignar pt = &y; *pt = 44;:

Dir: 3000 44 Variable x
Dir: 3010 44 Variable y
Dir: 3016 3010 Puntero pt

El mismo código (*pt = 44) puede afectar a distintas variables según la dirección asignada.

Dualidad entre Punteros y Tablas

A partir del momento de declaración de una tabla, su identificador actúa como un **puntero constante**:

  • Se pueden sumar/restar enteros a un puntero para desplazarse en memoria según el tamaño del tipo de dato.
  • Equivalencias fundamentales:

int x[4] = {1, 5, 2, 8};
int* pt = x + 2; // Apunta a la tercera posición (x[2])

// Las siguientes expresiones son equivalentes:
// pt[0]  <==>  *pt  <==>  x[2]  <==>  *(x + 2)

¿Para qué sirven los punteros?

USO 1: Acceso a elementos de tablas Permiten recorrer elementos en posiciones de memoria consecutivas.
USO 2: Modificación de variables en otras funciones Al pasar un puntero a una función, esta puede alterar directamente el valor original en la función llamante.

Tablas como Argumentos de Funciones

C no pasa tablas completas por valor; solo pasa la **dirección de comienzo**.

Por tanto, las siguientes declaraciones de argumentos son idénticas:

float MaxTabla(const float* tabla, int n) ≡ float MaxTabla(const float tabla[], int n)

Nota: Siempre es necesario pasar un segundo parámetro n con la longitud de la tabla.

Ejemplo: Máximo de una Tabla


float MaxTabla(const float* tabla, int n) {
    float maxi = tabla[0];
    int i;
    for (i = 1; i < n; i++) {
        if (tabla[i] > maxi) {
            maxi = tabla[i];
        }
    }
    return maxi;
}

int main(void) {
    float notas[5] = {8.5, 9.3, 7.1, 6.4, 5.0};
    int n_alumnos = 4;
    // Se pasa el nombre del array directamente (dirección base)
    float nota_max = MaxTabla(notas, n_alumnos); 
    return 0;
}

Consideraciones Importantes

  • Protección de datos con const: Utilizar const float* tabla impide que la función modifique accidentalmente el contenido de la tabla llamante.
  • Aritmética de direcciones: Se pueden pasar sub-tablas desplazando el puntero base (ej. Media(lluvia + 31, 28) para calcular la media de febrero).
  • Retorno de tablas: Una función nunca debe devolver un puntero a un array local, ya que se destruye al salir. Debe modificar una tabla pasada por argumento o usar asignación dinámica.

Salida de múltiples valores mediante Punteros

Como las funciones en C solo devuelven un valor mediante return, se usan punteros para "retornar" múltiples resultados.


// Devuelve el valor máximo Y su índice (*pt_imax)
float MaxTabla(const float* tabla, int n, int* pt_imax) {
    float maxi = tabla[0];
    int i;
    *pt_imax = 0;
    
    for (i = 1; i < n; i++) {
        if (tabla[i] > maxi) {
            maxi = tabla[i];
            *pt_imax = i; // Modifica la variable del llamante
        }
    }
    return maxi;
}

// Llamada: MaxTabla(notas, n_alumnos, &mejor_alumno);

Asignación Dinámica de Memoria

Permite reservar memoria en tiempo de ejecución en la zona del **Heap** (incluir <stdlib.h> o <malloc.h>):

  • void* malloc(int nBytes); Reserva espacio en bytes consecutivas. Devuelve NULL si no hay memoria disponible.
  • void free(void* ptr); Libera la memoria previamente asignada.

float *t;
int n = 100;

t = (float*) malloc(n * sizeof(float)); // Reserva para 'n' floats
if (t != NULL) {
    t[0] = 8.5; // Se usa exactamente como un array convencional
    free(t);    // Obligatorio liberar al finalizar
}

Punteros y Estructuras (->)

Para evitar copiar estructuras voluminosas en llamadas a funciones, se pasan punteros a estructura.

Para acceder a los campos desde un puntero:

Sintaxis clásica: (*v).n  |  Sintaxis preferida: v->n


struct vector {
    int n;
    float datos[100];
};

float Sumatorio(const struct vector* v) {
    float suma = 0;
    int i;
    for (i = 0; i < v->n; i++) {
        suma += v->datos[i];
    }
    return suma;
}

Representación de Matrices Dinámicas

Las matrices se representan mediante estructuras con puntero dinámico y organización en **Row-Major Order**:

Fórmula de mapeo 2D a 1D: elem[i][j] → data[i * cols + j]


struct matrix {
    int rows, cols;
    float *data;
};

struct matrix AsignaMemoriaMatriz(int nf, int nc) {
    struct matrix m;
    m.rows = nf;
    m.cols = nc;
    m.data = (float*) malloc(nf * nc * sizeof(float));
    return m;
}

Resumen del Tema

  1. Un array representa posiciones de memoria contiguas accedidas por un índice base 0.
  2. El nombre de un array es un puntero constante a su primera posición.
  3. Los punteros permiten el acceso indirecto a variables y el paso por referencia a funciones.
  4. El modificador const protege las tablas contra modificaciones no deseadas en funciones.
  5. malloc y free permiten gestionar la memoria de manera flexible y eficiente en el Heap.
