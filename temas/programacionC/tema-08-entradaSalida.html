E/S por Stream: Arquitectura

Permite a los programas intercambiar información con dispositivos periféricos mediante abstracciones unificadas:

Programa Usuario Llamadas a la API C
↔
Sistema Operativo Streams e Interrupciones
↔
Driver Dispositivo Acceso a Puertos
↔
Periférico / Archivo Hardware Físico

El SO gestiona la organización lógica y derechos de acceso; los drivers se encargan de la comunicación física con los puertos E/S e interrupciones.

¿Qué es un Stream?

Un **Stream** (corriente) es una secuencia ordenada de bytes enviada a o recibida desde un dispositivo. Todos los dispositivos se tratan de forma homogénea.

  • Según dirección: Entrada, Salida o Entrada/Salida bidireccional.
  • Según soporte: Con memoria (archivos en disco) o Sin memoria (teclado, pantalla, puerto serie).
  • Según formato: Orientados a Texto o Binarios.
  • Identificación: Mediante cadena de caracteres (ej. "COM1", "/dev/ttyS0", "C:\\datos.txt").

Apertura y Cierre: fopen y fclose

Para manipular un stream se incluye <stdio.h> y se utiliza un puntero al identificador de tipo opaco FILE*.


FILE* fopen(const char* name, const char* mode);
int fclose(FILE* fid);
Modo Operación Comportamiento
"r" / "rb" Lectura Abre archivo existente. Devuelve NULL si no existe.
"w" / "wb" Escritura Crea un archivo nuevo o sobrescribe/vacía si ya existía.
"a" / "ab" Añadir (Append) Abre o crea el archivo para escribir siempre al final.
"r+" / "w+" Lectura/Escritura Apertura combinada para actualizar información.

E/S Orientada a Texto

Caracteres: fgetc / fputc int fgetc(FILE* fid);
int fputc(int car, FILE* fid);
Cadenas: fgets / fputs char* fgets(char* str, int n, FILE* fid);
int fputs(const char* str, FILE* fid);
Formateada: fscanf / fprintf int fscanf(FILE* fid, char* fmt, ...);
int fprintf(FILE* fid, char* fmt, ...); 

FILE* f = fopen("salida.txt", "w");
if (f != NULL) {
    fprintf(f, "Resultado: %d\n", 42);
    fputs("Línea completada\n", f);
    fclose(f);
}

Streams Estándar y Redirección

Al iniciar un programa se abren automáticamente tres streams conectados a la consola:

  • stdin: Entrada estándar (teclado).
  • stdout: Salida estándar (pantalla).
  • stderr: Salida de errores (pantalla).

Las funciones convencionales de consola son alias de streams: printf(...) ≡ fprintf(stdout, ...).

Redirección en línea de comandos:

Miprograma.exe < entrada.txt > salida.txt

Entrada/Salida Binaria

Permite transferir bloques crudos de memoria desde/hacia un archivo sin conversiones de formato o formato numérico a texto.


// Lectura binaria
int fread(void* buffer, size_t size, size_t count, FILE* fid);

// Escritura binaria
int fwrite(const void* buffer, size_t size, size_t count, FILE* fid);
Parámetro buffer Dirección de memoria inicial de la variable o array.
Parámetros size y count Tamaño en bytes de cada elemento (sizeof) y número de elementos. Devuelven el total de elementos leídos/escritos con éxito.

Navegación y Posicionamiento

Funciones para consultar y desplazar el cursor dentro de archivos con memoria:

  • long ftell(FILE* fid); Devuelve la posición actual (en bytes) desde el inicio.
  • void rewind(FILE* fid); Vuelve a colocar el cursor al principio del archivo.
  • int fseek(FILE* fid, long offset, int origin); Desplaza el cursor $offset$ bytes según el origen:
    • SEEK_SET: Desde el principio del archivo.
    • SEEK_CUR: Desde la posición actual.
    • SEEK_END: Desde el final del archivo.

Control de Estado y Vaciado de Buffers

feof(fid) Devuelve distinto de cero (TRUE) cuando se alcanza el fin del archivo.
ferror(fid) / clearerr(fid) Consulta el código del último error (0 = OK) o limpia los indicadores de error del stream.
fflush(fid) Fuerza la escritura física en el dispositivo de los datos pendientes en el buffer intermedio del SO. En streams de entrada elimina datos residuales del buffer.

E/S Sin Buffer (Bajo Nivel)

Se realiza el acceso directamente contra los drivers sin conversiones intermedias ni memoria intermedia de stream:

  • Identificador de dispositivo: Un número entero (descriptor de archivo) de tipo int.
    • 0 ≡ stdin, 1 ≡ stdout, 2 ≡ stderr.
  • Funciones típicas (POSIX / Unix): open(), close(), read(), write(), creat(), tell().
  • Acceso a llamadas avanzadas del SO: ioctl(), fcntl(), select().

Ejemplo: Lectura de Matriz desde Fichero


#include <stdio.h>
#include <stdlib.h>

int main(void) {
    FILE* f = fopen("matriz.txt", "r");
    int n, m, i, j;
    float* datos;

    if (f == NULL) return -1;

    fscanf(f, "%d %d", &n, &m); // Lee dimensiones
    datos = (float*) malloc(n * m * sizeof(float));

    for (i = 0; i < n; i++) {
        for (j = 0; j < m; j++) {
            fscanf(f, "%f", &datos[i * m + j]); // Lee elementos
        }
    }
    fclose(f);
    free(datos);
    return 0;
}

Ejercicios Propuestos

  1. Leer los datos de una matriz de reales desde un fichero de texto con dimensiones $n \times m$ en cabecera.
  2. Desarrollar un programa que lea un archivo línea a línea y cuente cuántas líneas contienen una cadena buscada.
  3. Crear un programa que reemplace en un fichero la marca "<x>" por el valor entero de una variable elegida por teclado.
  4. Leer el máximo número de floats de un archivo binario y guardarlos formateados en una matriz en un archivo de texto.
  5. Implementar la lectura de matriz desde archivo cuando no se conocen de antemano $n$ y $m$ en la primera línea.

Resumen del Tema

  1. El modelo de Streams en C abstrae el intercambio de información con cualquier periférico o archivo.
  2. fopen permite seleccionar modos de apertura en texto o binario.
  3. Para ficheros formateados usar fprintf/fscanf; para grandes volúmenes de datos crudos usar fwrite/fread.
  4. Comprobar siempre que fopen no devuelva NULL antes de operar sobre un stream.
  5. Utilizar fflush cuando sea crítico asegurar la escritura inmediata sobre hardware.
