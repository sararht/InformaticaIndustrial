Tipos de datos básicos

Los datos pueden ser de varios tipos:

  • int: Para almacenar y realizar operaciones con valores enteros.
  • float: Para almacenar y realizar operaciones con valores reales.
  • char: Para almacenar y realizar operaciones con texto.

El programa puede utilizar datos de dos procedencias:

  • Variables: Valores que pueden cambiar a lo largo de la ejecución.
  • Constantes: Valores fijos que no cambian a lo largo del programa.

Variables y Constantes


// Variables
int n_alumnos;              // Variable tipo entero, sin inicializar
float nota_media = 7.25;    // Variable tipo real, valor inicial 7.25

// Constantes
// Preferible declararlas con #define al principio del código:
#define PI 3.1416

// Uso posterior mediante su identificador:
float z = 2 * cos(PI / 4);

Tipos de datos no básicos

Para representar conceptos que no son tipos nativos (meses, frutas, colores, complejos), se adaptan a tipos manejables:

  • Meses o Frutas: Se asocia un número entero a cada elemento mediante #define. 
    
#define ENERO 1
#define FEBRERO 2
int mes = FEBRERO;
  • Colores: Combinación RGB mediante 3 valores float de 0 a 1.
  • Números Complejos: 2 valores float (parte real y parte imaginaria).

Sentencias y Expresiones

Sentencia básica: Asignación.

variable = expresión;

Expresión: Resultado de una operación matemática con operandos y operadores:

  • Operadores aritméticos: +, -, *, /, paréntesis (), etc.
  • Operandos: Variables, constantes o funciones matemáticas (cos, sin, sqrt, etc.).

#include <math.h>
// Ejemplo de sentencia con funciones matemáticas
z = 3 * y + (2 * cos(PI / 4));

Evaluación de Expresiones

El compilador divide la expresión en una secuencia de operaciones según su orden de prioridad:

z = 3 * y + (2 * cos(PI / 4));

1. PI / 4 → r1
↓
2. cos(r1) → r2
↓
3. 2 * r2 → r3
↓
4. 3 * y → r4
↓
5. r4 + r3 → r5
↓
6. z = r5 (Almacenado en memoria)

Operaciones parciales y tipos

Cada operación parcial utiliza los tipos de sus operandos y devuelve un resultado de ese mismo tipo:

  • int OP int → int
  • float OP float → float
  • int OP float → float

int x = 4, y = 8;
float z;

z = x / y; // ¡ATENCIÓN! Operación entera: 4 / 8 resulta en 0.
           // z toma el valor 0.0 (float)

Operador Molde (Cast)

Para forzar una conversión explícita de tipo sin cambiar la naturaleza de la variable original:

(tipo) operando


int profes = 4, alumnos = 8;
float ratio;

// Conversión explícita a float de los operandos
ratio = (float)profes / (float)alumnos; 

// Ejecución: 4.0f / 8.0f = 0.5f -> ratio pasa a valer 0.5

Sentencias de Control


// Bloque
{
    sentencia1;
    sentencia2;
}

// Alternativa
if (condicion)
    sentenciaSiTRUE;
else
    sentenciaSiFALSE;

// Bucles
while (condicion)
    sentenciaARepetir;

for (init; condicion; paso)

Bloque { } Agrupa múltiples sentencias como una sola.
Alternativa if / else Ejecución condicional (else es opcional).
Bucles while / for Repiten instrucciones mientras la condición sea verdadera.

Evaluación de Condiciones

En C, las condiciones se evalúan como enteros:

  • FALSO: Valor igual a 0.
  • VERDADERO: Cualquier valor distinto de 0.

Operadores Relacionales: ==, !=, >, >=, <, <=.

Operadores Lógicos: && (AND), || (OR), ! (NOT).


// Ejemplo: y = min(|x|, 4)
if ((x > 4) || (x < -4)) {
    y = 4;
} else {
    if (x >= 0)
        y = x;
    else
        y = -x;
}

Diseño de Algoritmos

Un algoritmo traslada el pensamiento lógico a una secuencia ejecutable de instrucciones.

Ejemplo: Calcular el factorial: fact = n!

Expresión matemática abstracta: fact = n · (n-1) · (n-2) ...· 1

Secuencia algorítmica:

  1. Inicializar fact = 1.
  2. Repetir desde i = 1 hasta n: fact = fact * i.
  3. Al finalizar el bucle: fact contiene n!.

Traducción del Algoritmo a C


#include <stdio.h>

int main(void) {
    int n, i, fact;

    printf("Introduzca n: ");
    scanf("%d", &n);

    fact = 1;
    for (i = 1; i <= n; i++) {
        fact = fact * i;
    }

    printf("%d! = %d\n", n, fact);
    return 0;
}

Representación: Pseudocódigo y Diagramas

Pseudocódigo

Repetir desde i = 1 hasta n:
    fact = fact * i

Flujo Lógico
fact = 1, i = 1
↓
¿i <= n?
↓ Sí
fact = fact * i
i = i + 1

Desarrollo Top-Down y Optimización

Desarrollo Top-Down: Diseccionar un problema complejo en bloques más sencillos.

Ejemplo: Serie de Taylor para ex = ∑ (xn / n!)

Optimización de iteraciones: Aprovechar cálculos previos:

  • xn = x · xn-1
  • n! = n · (n - 1)!

Nota: Las optimizaciones aumentan la velocidad de ejecución pero pueden reducir la legibilidad.

Depuración de Programas

Un programa sin errores de compilación sintácticos no garantiza un comportamiento correcto.

Causas habituales de fallos:

  • Algoritmo mal concebido o mala traducción al lenguaje.
  • Uso incorrecto de tipos de datos o modificación indebida de variables.
  • Casos límite u ocasionales no contemplados.

Depuración: Proceso de prueba, localización y corrección de errores en el código.

Estructuras en C (struct)

Permiten agrupar variables de distintos tipos bajo un mismo nombre:


// Definición de la estructura
struct color {
    float red, green, blue;
};

struct circulo {
    float centrox, centroy, radio;
    struct color colorBorde, colorFondo;
    int anchoBorde, dibujarFondo;
};

// Uso e inicialización
struct circulo sol;
sol.colorFondo.red = 1.0;
sol.colorFondo.green = 1.0;
sol.colorFondo.blue = 0.0;
sol.dibujarFondo = 1;

Ejercicios Propuestos

  1. Cálculo de raíces reales o complejas de $a \cdot x^2 + b \cdot x + c = 0$.
  2. Cálculo de combinaciones de alineaciones titulares: $C_{n,m} = \frac{n!}{m! \cdot (n-m)!}$.
  3. Conversión de un número decimal (0-255) a su representación en binario de 8 bits.
  4. Verificación experimental de la aproximación de $e$: $\sum_{n=0}^{\infty} \frac{1}{n!}$ vs $\lim_{n \to \infty} (1 + \frac{1}{n})^n$.
  5. Búsqueda del mínimo de un polinomio cuadrático mediante el método Golden-Search.
