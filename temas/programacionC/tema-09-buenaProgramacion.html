Tipos de Datos y Memoria

Detalles clave para un uso correcto de la memoria:

  • Desbordamiento (Overflow): C no comprueba la salida de rango en enteros; es responsabilidad del programador prevenirla.
  • Coma fija: Opción eficiente para números reales en microcontroladores sin unidad de coma flotante (FPU).
  • Endianness: Las variables multibyte se almacenan en memoria en formato Little-Endian o Big-Endian.
  • Operador sizeof(): Determina el tamaño exacto en bytes de cualquier tipo de dato o variable en tiempo de compilación.
  • Definición de tipos: Uso de struct, union, enum y typedef para estructurar datos complejos.

Variables y Expresiones Avanzadas

Variables y Arrays
  • Uso estratégico de variables globales y estáticas (static).
  • Arrays multidimensionales estáticos y dinámicos (reservar solo cuando sea imprescindible).
Operadores Abreviados
  • Asignación combinada: +=, -=, *=, /=.
  • Incremento y decremento: ++, --.
  • Operador ternario condicional: ? :
  • Operador coma (,) para encadenar expresiones.

Funciones y la Librería Estándar

Mecanismos avanzados para la modularidad y llamadas avanzadas:

  • Firma completa de main: int main(int argc, char* argv[]) recibe parámetros desde la línea de comandos del sistema operativo.
  • Punteros a función: Permiten la invocación dinámica de funciones en tiempo de ejecución.

Librerías ANSI C fundamentales:

<math.h> Cálculo matemático
<string.h> Manejo de cadenas
<stdlib.h> / <malloc.h> Memoria dinámica
<stdio.h> Entrada y Salida
<time.h> Fecha y hora
<ctype.h> Prueba de caracteres

Criterios al Escribir el Código

  • Pruebas unitarias aisladas: Diseñar y probar cada función de forma independiente antes de integrarla.
  • Funciones puras y genéricas: Evitar incluir printf() o scanf() dentro de funciones de cálculo.
  • Gestión de errores: Las funciones deben devolver códigos de error o estado si no pueden completar su tarea.
  • Evitar variables globales: Minimizar su uso dentro de funciones para evitar efectos secundarios descontrolados.
  • Compilación separada: Agrupar funciones afines en módulos .c con su correspondiente archivo .h.
  • Legibilidad y documentación: Utilizar #define para constantes simbólicas y añadir comentarios claros en las cabeceras.

Prueba y Depuración de Programas

Un código que compila no es suficiente La ausencia de errores sintácticos no garantiza un comportamiento lógico correcto.
Aislamiento de fallos Probar cada módulo/función por separado simplifica enormemente la localización de errores.
Usar herramientas de Depuración (Debugger) Aprovechar los puntos de interrupción (breakpoints) e inspección de memoria en lugar de saturar el código con printf() temporales.
Casos límite y anómalos Verificar minuciosamente la respuesta del programa ante entradas no válidas o situaciones límite.

Resumen General del Curso

  1. Escribir código modular, legible y auto-explicativo.
  2. Encapsular la lógica en funciones genéricas y reutilizables.
  3. Proteger la integridad de la memoria supervisando índices y punteros.
  4. Dominar la compilación separada y las herramientas de depuración.
