El computador

Una máquina de ejecución secuencial de instrucciones

  • Cada instrucción es una operación muy sencilla, que utiliza datos fuente y almacena el resultado en datos destino.

MOV dest, src ; dest = src
ADD dest, src ; dest = dest + src
NEG dest ; dest = -dest
DIV dest, src ; dest = dest / src
  • Los datos o variables son lugares de almacenamiento de información: guardan valores que pueden ser requeridos o modificados posteriormente.
  • Un programa es una secuencia de instrucciones sencillas.

MOV m, x1 ; m = x1
ADD m, x2 ; m = m + x2 = x1 + x2
ADD m, x3 ; m = m + x3 = x1 + x2 + x3
DIV m, 3 ; m = m / 3 = (x1 + x2 + x3) / 3

Codificación de datos e instrucciones

Para interpretar instrucciones y datos, el computador utiliza un código común

  • Las instrucciones se representan mediante secuencias de símbolos que la CPU interpreta como operaciones.
  • Los datos enteros se representan mediante dígitos, que forman un número con valor posicional.
  • En el sistema decimal, el orden de los dígitos determina el peso de cada posición.

Representación decimal

Codificación ponderada en base 10

Ejemplo: 2014

  • El valor depende del peso de cada dígito.
  • La posición más a la derecha representa las unidades.
  • Las posiciones posteriores representan decenas, centenas, millares, etc.

Operaciones con datos

La suma en base 10 sigue reglas de acarreo

  • Se suman primero los dígitos de menor peso.
  • Si el resultado excede la base, se genera un acarreo hacia el siguiente peso.
  • El proceso se repite para todos los pesos, de derecha a izquierda.

    2717
  +  714
  ------
    3431

Codificación binaria

El computador utiliza solo dos símbolos: 0 y 1

  • El sistema binario es una codificación ponderada en base 2.
  • Una misma cantidad puede expresarse en distintos sistemas de numeración.
  • Por ejemplo, el número 14 puede escribirse como 14 en decimal o como 1110 en binario.

Memoria y direcciones

Datos e instrucciones se almacenan en memoria

  • La memoria está organizada en direcciones, numeradas secuencialmente.
  • Cada dirección almacena 1 byte, es decir 8 bits.
  • Si un dato no cabe en una sola dirección, ocupa varias direcciones consecutivas.
  • La CPU también dispone de registros específicos para datos internos.

Partes del computador

CPU, memoria y periféricos

Unidad central de proceso (CPU)

Ejecuta instrucciones. Está formada por la unidad aritmético-lógica (ALU), la unidad de control (UC) y registros internos.

Memoria principal

Almacena datos y programas en RAM. La CPU accede a ella para leer instrucciones y operandos.

Dispositivos de entrada/salida

Permiten la comunicación con el entorno físico: teclado, pantalla, sensores, actuadores, buses y puertos.

Bus

Es el conjunto de líneas que conectan la CPU con la memoria y los periféricos para transferir datos e instrucciones.

Ejecución secuencial de una instrucción

Fetch, decode, execute y write-back

  1. La CPU obtiene la instrucción desde la memoria.
  2. La unidad de control la decodifica y determina la operación a realizar.
  3. La ALU o el circuito correspondiente ejecuta la operación.
  4. El resultado se almacena en un registro o en memoria.

Computador y ejecución secuencial

El procesador realiza una instrucción tras otra

Ensamblador

En bajo nivel, la máquina trabaja con instrucciones simples como carga, suma, comparación y salto.


MOV R1, [mem]
ADD R1, R2

Lenguaje C

C proporciona una abstracción más legible para expresar el mismo comportamiento: variables, expresiones y llamadas a funciones.

Estructura mínima de un programa en C

Cabecera, función principal y retorno


#include <stdio.h>

int main(void) {
    int sensor_id = 1;
    float voltaje = 3.3f;

    printf("Sensor %d: %.2f V\n", sensor_id, voltaje);
    return 0;
}

Variables e identificadores

Los nombres de las variables permiten acceder a datos de forma legible

Identificador

Es el nombre que utiliza el programador para referirse a una posición de memoria.

Declaración

Una variable se declara con un tipo y un identificador, por ejemplo: int temperatura;.

Tipos de datos básicos

Cada tipo define el formato y el tamaño de la información

char

Almacena un carácter o un entero pequeño. Ocupa 1 byte.

int

Representa enteros para contadores, estados y valores discretos.

float

Representa valores reales con precisión simple.

double

Representa valores reales con mayor precisión.

Operadores aritméticos y de asignación

Permiten transformar y actualizar valores

Aritméticos

+, -, *, / y % permiten operar con variables numéricas.

Asignación

= asigna un valor, y las formas compuestas como +=, ++ o -- simplifican expresiones comunes.

Entrada y salida básica

La comunicación con el exterior se realiza mediante funciones estándar

printf()

Se usa para mostrar información en consola o terminal.


printf("Temperatura: %d C\n", temp);

scanf()

Se usa para leer una entrada del usuario desde el teclado.


scanf("%d", &consigna);

Relación con la memoria física

Desde C hasta el microcontrolador o PLC

  • Cada variable ocupa una región de memoria con un tamaño fijo.
  • El compilador asigna esa variable a una dirección de memoria concreta.
  • En sistemas embebidos, esa memoria corresponde a registros, RAM o áreas de trabajo del controlador.
  • Por eso, el tipo de dato no es solo una convención teórica, sino una decisión de diseño real.

Ejemplo práctico: lectura y cálculo

Escalado de un valor analógico de entrada


#include <stdio.h>

int main(void) {
    int adc_val = 512;
    float v_ref = 5.0f;
    float voltaje_medido;

    voltaje_medido = (adc_val / 1023.0f) * v_ref;

    printf("ADC = %d\n", adc_val);
    printf("Voltaje = %.2f V\n", voltaje_medido);
    return 0;
}

Resumen del tema

  1. El computador ejecuta instrucciones de forma secuencial.
  2. Las variables son nombres asociados a memoria.
  3. Los tipos básicos definen el tamaño y la representación del valor.
  4. Los operadores permiten transformar datos y producir resultados.
  5. printf y scanf permiten comunicar datos con el exterior.
