El Computador y sus Instrucciones

Un computador es una máquina de ejecución secuencial de instrucciones:

  • Cada instrucción es una operación muy sencilla que opera sobre datos. Intrucciones básicas (Ensamblador):
    • MOV dest, src → Copia el contenido de src en dest.
    • ADD dest, src → Suma: dest = dest + src.
    • NEG dest → Cambia de signo: dest = -dest.
    • DIV dest, src → Divide: dest = dest / src.
  • Los datos (o variables) son lugares de almacenamiento de información: guardan valores que pueden ser requeridos o modificados posteriormente.
  • Un programa es una secuencia de instrucciones sencillas encargadas de resolver un problema (ej. media de 3 valores).
    • 
              MOV m, x1   ; m = x1
              ADD m, x2   ; m = m+x2 = x1+x2
              ADD m, x3   ; m = m+x3 = x1+x2+x3
              DIV m, 3    ; m = m/3 = (x1+x2+x3)/3

Codificación de Datos y Sistemas de Numeración

Un computador codifica la información en binario para poder almacenarla y procesarla.

Una misma cantidad puede expresarse en distintos sistemas de numeración:

  • Sistemas no ponderados (ej. Romanos): Dificultan la realización simple de operaciones aritméticas (ej. XIV).
  • Decimal Ponderado (Base 10): Emplea dígitos 0..9 con pesos basados en potencias de 10 (101, 100).
  • Binario Ponderado (Base 2): Emplea 0 y 1 con pesos en potencias de 2 (24, 23, 22, 21, 20).

Organización Binaria en Memoria y Registros

Tanto los datos como las instrucciones se codifican en binario y se guardan en la memoria principal:

  • Direcciones de Memoria: La memoria se organiza en posiciones numeradas desde 0 hasta 2n - 1.
  • Unidad Byte: Cada dirección almacena exactamente 1 byte = 8 bits. Si un valor no cabe en un byte, ocupa varias direcciones consecutivas.
  • Registros de Control:
    • PC (Contador de Programa): Almacena la dirección de memoria de la siguiente instrucción a ejecutar.
    • SW (Registro de Estado): Guarda flags de condición tras cada operación, como ZF (Zero Flag: se activa si el resultado es cero) y SF (Sign Flag: se activa si es negativo).

Ejecución de Programas

    Un programa es una secuencia de instrucciones que el procesador ejecuta en orden secuencial:

  • Cada instrucción es muy básica: usa 1, 2 o 3 operandos y realiza una copia, suma, resta, multiplicación o división.
  • Los operandos se expresan como contenidos de direcciones de memoria o valores inmediatos
  • Tanto instrucciones como operandos se codifican en binario

El Computador: Periféricos

Los periféricos (o dispositivos de Entrada/Salida) sirven para que la CPU intercambie información con el “exterior”.

De cara a la CPU, la E/S es similar a la memoria:

  • Está organizada en direcciones (mapa de E/S).
  • Se intercambia con ella datos binarios (instrucciones IN, OUT.

La diferencia:

  • Cada bit de cada dirección de E/S está físicamente conectado a un dispositivo externo.

El Computador: Periféricos

La mayoría de periféricos realizan operaciones más sofisticadas con los valores binarios de las direcciones de E/S a las que están conectados:

  • Teclado: cuando se pulsa una tecla, escribe en la dirección de E/S correspondiente un código (ASCII) según la tecla pulsada
  • a
    01100001
    B
    01000010
    ↵
    00001010
  • Pantalla: cuando la CPU escribe un código (ASCII) en la dirección de E/S correspondiente, genera puntos luminosos en los lugares adecuados para que el observador visualice el carácter equivalente
  • 01100001

El Computador

¿Cómo se cargan instrucciones y datos en memoria?

  • Se utiliza un programa “cargador” que vuelque los contenidos de un archivo (programa ejecutable) en memoria: instrucciones y datos

¿Cómo se ordena la ejecución del programa?

  • Se indica al programa “cargador” la dirección de la 1ª instrucción.
  • Una vez se ejecuta la 1ª instrucción, las siguientes se ejecutan secuencialmente (salvo los casos de salto).

¿Es necesario conocer y escribir programas en código binario?

  • No, existen programas más sofisticados (compiladores e intérpretes) que nos permiten traducir a código máquina desde lenguajes de “alto nivel” (similares al lenguaje matemático).

El Lenguaje de Alto Nivel (C)

Permite escribir algoritmos utilizando notación matemática comprensible en lugar de código máquina binario.

Código Máquina / Ensamblador 

MOV m, x1
ADD m, x2
ADD m, x3
ADD m, x4
DIV m, 4
Lenguaje de Alto Nivel (C) 

int x1, x2, x3, x4;
float m;

m = (x1 + x2 + x3 + x4) / 4.0;

El Compilador es el programa encargado de traducir el código fuente a código máquina específico para cada procesador.

Reglas Fundamentales del Lenguaje C

  • Declaración previa: Toda variable debe declararse con su tipo (int, float, char) antes de usarse.
  • Sensibilidad a mayúsculas: C distingue mayúsculas de minúsculas en palabras clave e identificadores.
  • Función main(): Todo código ejecutable debe residir dentro de una función (la principal es main).
  • Fin de sentencia: Cada sentencia finaliza con un punto y coma (;).
  • Comentarios: De línea con // o de bloque con /* ... */ (son ignorados por el compilador).

Salida por Consola


printf("texto a escribir", valor1, valor2, ...);
  • Escribe en pantalla los caracteres de la cadena de texto, excepto cuando aparece %algo.
  • El %algo se sustituye por el valor correspondiente de la lista (siguiendo el estricto orden de aparición):
    • %d: entero (int)
    • %f: real / flotante (float)
    • %c: carácter individual (char)
    • %s: cadena de caracteres (texto)
  • La secuencia de escape \n en el texto representa un salto de línea (retorno de carro).
Ejemplo de Código C: 

int alumnos = 12;
float nota_media = 7.25;

printf("Hay %d alumnos, nota media %f\n", alumnos, nota_media);
Resultado en pantalla:
Hay 12 alumnos, nota media 7.250000

Entrada por Consola


scanf("formato", direccion_valor1, direccion_valor2, ...);
  • Espera por teclado la pulsación de una secuencia de caracteres terminada en INTRO.
  • El texto del formato sólo debe contener cadenas de formato (%algo).
  • Las direcciones se indican anteponiendo a cada variable el carácter &.
  • El usuario debe separar cada entrada con espacio, tabulador o Return, y siempre terminar con Return.
Ejemplo de Código C: 

                int alumnos;
                float nota_media;

                printf("Introduzca alumnos y nota media: ");
                scanf("%d %f", &alumnos, &nota_media);
                printf("Hay %d alumnos, nota media %f\n", alumnos, nota_media);
Resultado en pantalla:
Introduzca alumnos y nota media: 12  7.25↵
Hay 12 alumnos, nota media 7.250000
⚠️ Nota: Olvidar el operador & en scanf() provocará un error de ejecución al intentar escribir en una dirección de memoria errónea.

El lenguaje de alto nivel (C)

Ejemplo: dados el radio y el número de lados de un polígono regular, calcular su perímetro

Datos:
n_lados (debe ser entero)
radio (puede ser real)
Resultado:
perim (puede ser real)
Cálculo:
perim = lado * n_lados
donde lado se obtiene de:
sin(ang/2) = lado/2 radio
y ang se obtiene de:
ang = 2π / n_lados
En rojo/cursiva: variables necesarias (cambian su valor en función de los datos iniciales y/o de la evolución de los cálculos).

Ejemplo Completo: Perímetro de un Polígono

Implementación en C del cálculo del perímetro de un polígono regular 


#include <stdio.h>
#include <math.h>

#define PI 3.1416 // Constante

int main(void) {
    int n_lados;        // Entrada: número de lados
    float radio;        // Entrada: radio del polígono
    float perim;        // Salida: perímetro calculado
    float ang, lado;    // Variables auxiliares

    printf("Introduzca n lados: ");
    scanf("%d", &n_lados);
    printf("Introduzca radio: ");
    scanf("%f", &radio);

    ang = 2 * PI / n_lados;
    lado = 2 * radio * sin(ang / 2.0f);
    perim = n_lados * lado;

    printf("El perímetro es %f\n", perim);
}

Resumen del Tema

  1. Un computador ejecuta instrucciones binarias simples de manera secuencial controladas por el registro PC.
  2. La memoria se organiza en direcciones de 1 byte, almacenando tanto código como variables.
  3. Los lenguajes de alto nivel como C permiten expresar algoritmos matemáticos legibles que el compilador traduce a binario.
  4. printf y scanf gestionan la comunicación con la consola usando especificadores de formato (%d, %f).
