El Computador y sus Instrucciones

Un computador es una máquina de ejecución secuencial de instrucciones:

  • Cada instrucciónes una operación muy sencilla que opera sobre datos. Intrucciones básicas (Ensamblador):
    • MOV dest, src → Copia el contenido de src en dest.
    • ADD dest, src → Suma: dest = dest + src.
    • NEG dest → Cambia de signo: dest = -dest.
    • DIV dest, src → Divide: dest = dest / src.
  • Los datos (o variables) son lugares de almacenamiento de información: guardan valores que pueden ser requeridos o modificados posteriormente.
  • Un programa es una ecuencia de instrucciones sencillas encargadas de resolver un problema (ej. media de 3 valores).
    • 
              MOV m, x1   ; m = x1
              ADD m, x2   ; m = m+x2 = x1+x2
              ADD m, x3   ; m = m+x3 = x1+x2+x3
              DIV m, 3    ; m = m/3 = (x1+x2+x3)/3

Codificación de Datos y Sistemas de Numeración

Una misma cantidad puede expresarse en distintos sistemas de numeración:

  • Sistemas no ponderados (ej. Romanos): Dificultan la realización simple de operaciones aritméticas (ej. XIV).
  • Decimal Ponderado (Base 10): Emplea dígitos 0..9 con pesos basados en potencias de 10 (101, 100).
  • Binario Ponderado (Base 2): Emplea 0 y 1 con pesos en potencias de 2 (24, 23, 22, 21, 20).

Organización Binaria en Memoria y Registros

Tanto los datos como las instrucciones se codifican en binario y se guardan en la memoria principal:

  • Direcciones de Memoria: La memoria se organiza en posiciones numeradas desde 0 hasta 2n - 1.
  • Unidad Byte: Cada dirección almacena exactamente 1 byte = 8 bits. Si un valor no cabe en un byte, ocupa varias direcciones consecutivas.
  • Registros de Control:
    • PC (Contador de Programa): Almacena la dirección de memoria de la siguiente instrucción a ejecutar.
    • SW (Registro de Estado): Guarda banderas de condición tras cada operación, como ZF (Zero Flag: se activa si el resultado es cero) y SF (Sign Flag: se activa si es negativo).

Ejecución de Programas

    Un programa es una secuencia de instrucciones que el procesador ejecuta en orden secuencial:

  • Cada instrucción es muy básica: usa 1, 2 o 3 operandos y realiza una copia, suma, resta, multiplicación o división.
  • Los operandos se expresan como contenidos de direcciones de memoria o valores inmediatos
  • Tanto instrucciones como operandos se codifican en binario

  • Instrucciones específicas (de salto) tienen como destino el contador de programa (PC)

El Lenguaje de Alto Nivel (C)

Permite escribir algoritmos utilizando notación matemática comprensible en lugar de código máquina binario.

Código Máquina / Ensamblador 

MOV m, x1
ADD m, x2
ADD m, x3
ADD m, x4
DIV m, 4
Lenguaje de Alto Nivel (C) 

int x1, x2, x3, x4;
float m;

m = (x1 + x2 + x3 + x4) / 4.0;

El Compilador es el programa encargado de traducir el código fuente a código máquina específico para cada procesador.

Reglas Fundamentales del Lenguaje C

  • Declaración previa: Toda variable debe declararse con su tipo (int, float, char) antes de usarse.
  • Sensibilidad a mayúsculas: C distingue mayúsculas de minúsculas en palabras clave e identificadores.
  • Función main(): Todo código ejecutable debe residir dentro de una función (la principal es main).
  • Fin de sentencia: Cada sentencia finaliza con un punto y coma (;).
  • Comentarios: De línea con // o de bloque con /* ... */ (son ignorados por el compilador).

Entrada / Salida por Consola

Salida con printf() Escribe texto en pantalla con especificadores de formato:
  • %d: Entero (int)
  • %f: Real (float)
  • %c: Carácter (char)
  • %s: Cadena de texto
  • \n: Salto de línea
Entrada con scanf() Lee datos introducidos por teclado: 

int alumnos;
float nota;

printf("Datos: ");
scanf("%d %f", &alumnos, ¬a);
Nota: Es obligatorio el operador & antes de la variable para indicar su dirección de memoria.

Ejemplo Completo: Perímetro de un Polígono


#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define PI 3.1416 // Constante del preprocesador

int main(void) {
    int n_lados;        // Entrada: número de lados
    float radio;        // Entrada: radio del polígono
    float perim;        // Salida: perímetro calculado
    float ang, lado;    // Variables auxiliares

    printf("Introduzca n lados: ");
    scanf("%d", &n_lados);
    printf("Introduzca radio: ");
    scanf("%f", &radio);

    ang = 2.0 * PI / n_lados;
    lado = 2.0 * radio * sin(ang / 2.0);
    perim = n_lados * lado;

    printf("El perímetro es %f\n", perim);
    return 0;
}

Ejercicios Propuestos

  1. Pedir dos instantes de tiempo (horas, minutos, segundos) y calcular el intervalo transcurrido en segundos.
  2. Pedir los dos lados de un rectángulo y calcular la longitud de su diagonal ($d = \sqrt{a^2 + b^2}$).
  3. Pedir dos puntos en 2D $(x_1, y_1)$ y $(x_2, y_2)$, calcular la recta $y = mx + n$ y evaluar $y$ para un $x$ cualquiera.
  4. Convertir una temperatura dada en grados Fahrenheit (°F) a grados Celsius (°C).
  5. Pedir velocidad inicial, velocidad final y tiempo transcurrido para calcular el espacio recorrido y la aceleración.
  6. Calcular el día de la semana correspondiente a cualquier fecha dada mediante la Congruencia de Zeller.

Resumen del Tema

  1. Un computador ejecuta instrucciones binarias simples de manera secuencial controladas por el registro PC.
  2. La memoria se organiza en direcciones de 1 byte, almacenando tanto código como variables.
  3. Los lenguajes de alto nivel como C permiten expresar algoritmos matemáticos legibles que el compilador traduce a binario.
  4. printf y scanf gestionan la comunicación con la consola usando especificadores de formato (%d, %f).
