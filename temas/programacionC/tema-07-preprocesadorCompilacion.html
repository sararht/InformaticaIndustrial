Fases de Obtención del Ejecutable

El proceso de transformación del código fuente a código ejecutable consta de varias etapas:

Editor .c / .h (Texto fuente)
→
Preprocesador Expansión de texto
→
Compilador .obj (Código objeto)
→
Enlazador (Linker) .exe + .lib

El Cargador (Loader) del sistema operativo vuelca el archivo .exe en la memoria RAM y establece el Registro Contador de Programa (PC) en la primera instrucción de main().

Compilación Separada

Permite dividir programas complejos en múltiples ficheros fuente independientes:

  • Modularidad: Cada fichero .c se compila de forma aislada generando su correspondiente fichero objeto .obj.
  • Reutilización y Eficiencia: Al modificar un único archivo, solo es necesario re-compilar ese módulo antes de volver a enlazar.
  • Enlazado final: El Linker une todos los .obj y las librerías estáticas (.lib) resolviendo los símbolos exported/extern.

El Preprocesador en C

Actúa antes del proceso de compilación propiamente dicho, realizando manipulaciones de texto sobre el código fuente.

Todas las directivas comienzan por el símbolo # y ocupan una sola línea:

#include Inserta textualmente el contenido de un fichero de cabecera.
#define Define constantes simbólicas o macros sustituibles por texto.
#if / #ifdef / #endif Permiten la compilación condicional del bloque de código.
#pragma / #error Instrucciones específicas al compilador o generación de errores customizados.

Ficheros Fuente (.c) vs. Cabeceras (.h)

Ficheros Fuente (.c)
  • Se compilan individualmente para generar archivos .obj.
  • Contienen el código ejecutable (definición de funciones, lógica, algoritmos).
  • Declaran el almacenamiento de variables globales.
Ficheros de Cabecera (.h)
  • Nunca se compilan directamente; se incluyen via #include en los .c.
  • Solo contienen declaraciones necesarias para los clientes del módulo:
    • Prototipos de función terminados en ;
    • Constantes e Inclusiones
    • Nuevos tipos (struct, enum, typedef)

Variables Globales Compartidas (extern)

Para compartir una variable global entre varios archivos fuente:

  • Módulo principal / Propietario (uno.c): Declara la variable para reservar memoria.
  • Módulo secundario (dos.c): Declara la variable anteponiendo la palabra clave extern.

// ----- Fichero: uno.c -----
#include "dos.h"
int _vble_global = 10; // Reserva espacio en memoria RAM

int main(void) {
    FnDos();
    return 0;
}

// ----- Fichero: dos.c -----
#include "dos.h"
extern int _vble_global; // Indica al compilador que existe en otro .obj

void FnDos(void) {
    _vble_global = 20;   // Modifica la variable global compartida
}

Macros con Parámetros

Sustituyen texto antes de compilar. A diferencia de una función, no generan sobrecarga de llamadas, pero deben construirse con precaución:


// Definición incorrecta (sin paréntesis):
#define CUADRADO(x) x * x
// Invocación: CUADRADO(1 + 2) -> Expande a: 1 + 2 * 1 + 2 = 5 (¡ERROR!)

// Definición correcta (con paréntesis en argumentos y expresión):
#define CUADRADO(x) ((x) * (x))
// Invocación: CUADRADO(1 + 2) -> Expande a: ((1 + 2) * (1 + 2)) = 9

// Macro segura de comparación:
#define MIN(a, b) (((a) < (b)) ? (a) : (b))

Compilación Condicional

Permite incluir o excluir fragmentos de código fuente durante la compilación.

Diferencia clave entre #if (Preprocesador) e if() (Lenguaje C):

  • #if: Se evalúa en tiempo de compilación. El código omitido **no se incluye** en el archivo binario final.
  • if(): Se evalúa en tiempo de ejecución. Todo el código forma parte del binario ejecutable.

#define DEPURANDO 1 // Cambiar a 0 en la versión de producción

int main(void) {
    int resultado = 42;
    
#if DEPURANDO > 0
    printf("DEBUG: Valor parcial de resultado = %d\n", resultado);
#endif

    return 0;
}

Protección contra Inclusión Múltiple (Include Guards)

Cuando varias cabeceras incluyen a su vez el mismo fichero .h, se produce un error de **duplicidad de tipos/estructuras** en compilación.

Solución: Envolver el contenido del fichero .h con la directiva #ifndef.


// ----- Fichero: matrices.h -----
#ifndef _INC_MATRICES_H
#define _INC_MATRICES_H

struct matriz {
    int filas;
    int columnas;
    float* datos;
};

void InicializarMatriz(struct matriz* m);

#endif // _INC_MATRICES_H

Ejercicios Propuestos

  1. Diseñar un programa modularizado en dos ficheros fuente (principal.c y funciones.c) y una cabecera (funciones.h) para calcular la desviación típica de un array.
  2. Implementar una macro segura con parámetros que genere la máscara binaria dado el bit de inicio y el número de bits del campo.
  3. Desarrollar un programa que gestione el desplazamiento de un array de reales e incluya un modo de traza configurable mediante #define y #ifdef para imprimir o no el contenido en cada iteración.

Resumen del Tema

  1. El preprocesador transforma textualmente el código antes de la compilación.
  2. Los archivos .c contienen la implementación ejecutable; las cabeceras .h exponen las interfaces públicas.
  3. Se utiliza extern para compartir el acceso a variables globales declaradas en otro módulo.
  4. Encerrar las macros parametrizadas siempre entre paréntesis para evitar errores de evaluación.
  5. Proteger **todas** las cabeceras .h mediante Include Guards (#ifndef ... #define ... #endif).
