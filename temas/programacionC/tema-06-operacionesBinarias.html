Codificación Binaria y E/S Digital

Un entero se representa mediante bits en base 2 (ponderación posicional):

  • El número total de bits depende del tipo de dato (ej. 8 * sizeof(int)).
  • Interés a nivel de bit: Cuando el valor aritmético global no importa, sino el estado individual de las líneas de hardware.
    • Entradas digitales (interruptores, pulsadores, sensores).
    • Salidas digitales (LEDs, relés, actuadores).
    • Compresión/Empaquetado de múltiples variables en un solo número entero.

Operadores Lógicos a Nivel de Bit

Operan sobre cada bit equivalente individualmente:

& (AND Lógico) 1 & 1 = 1; de lo contrario 0. Usado para filtrar bits.
| (OR Lógico) 0 | 0 = 0; de lo contrario 1. Usado para encender bits.
^ (XOR / OR Exclusivo) 1 si los bits son distintos, 0 si son iguales. Usado para bascular bits.
~ (NOT / Complemento) Invierte monáricamente todos los bits (0 → 1, 1 → 0).

Ejemplo de Operaciones Bit a Bit


int v1 = 77; // 0000 0000 ... 0100 1101
int v2 = 23; // 0000 0000 ... 0001 0111

int res_and = v1 & v2; // 0000 0000 ... 0000 0101 (5)
int res_or  = v1 | v2; // 0000 0000 ... 0101 1111 (95)
int res_xor = v1 ^ v2; // 0000 0000 ... 0101 1010 (90)
int res_not = ~v1;     // 1111 1111 ... 1011 0010 (-78)

Operadores de Desplazamiento

Desplazan los bits de un entero un número determinado de posiciones:

  • Desplazamiento a la izquierda (val << n):
    • Mueve los bits $n$ posiciones a la izquierda.
    • Rellena con ceros (0) por la derecha.
    • Equivale algebraicamente a multiplicar por $2^n$.
  • Desplazamiento a la derecha (val >> n):
    • Mueve los bits $n$ posiciones a la derecha.
    • Rellena con 0 si es tipo unsigned. Si es signed, conserva el bit de signo.
    • Equivale algebraicamente a la división entera por $2^n$.

int x = 26;        // 0000 ... 0001 1010  (26)
int izq = x << 3;  // 0000 ... 1101 0000  (208 -> 26 * 2³)
int der = x >> 3;  // 0000 ... 0000 0011  (3   -> 26 / 2³)

Operaciones con un Bit Individual

Para operar sobre el bit de peso $p$ en una variable $x$ mediante una máscara (mascara = 1 << p):


int x, p = 3;
int mascara = 1 << p; // Genera valor con solo el bit 'p' activo

// 1. CONSULTAR estado del bit 'p'
if (x & mascara) { /* Bit 'p' está a 1 */ }

// 2. PONER A 1 (Activar) el bit 'p'
x = x | mascara;     // x |= mascara;

// 3. PONER A 0 (Desactivar/Borrar) el bit 'p'
x = x & ~mascara;    // x &= ~mascara;

// 4. CONMUTAR (Invertir) el bit 'p'
x = x ^ mascara;     // x ^= mascara;

Empaquetado y Extracción de Datos

Supongamos una variable $v$ que empaqueta tres campos: $vx$ (bits 0..2), $vy$ (bit 3) y $vz$ (bits 4..5):


// Formato de v: ... [zz][y][xxx]
int v, vx, vy, vz;

// --- EXTRAER CAMPOS ---
vx =  v & 0x07;         // Máscara 000 0111 -> Aislar bits 0..2
vy = (v & 0x08) >> 3;   // Máscara 000 1000 -> Aislar bit 3 y desplazar
vz = (v & 0x30) >> 4;   // Máscara 011 0000 -> Aislar bits 4..5 y desplazar

// --- ESCRITURA / MODIFICACIÓN DE UN CAMPO (Ej: Modificar vz) ---
// 1. Limpiar campo con máscara invertida
// 2. Insertar nuevo valor con desplazamiento y máscara
v = (v & ~0x30) | ((vz << 4) & 0x30);

Macros para Máscaras Genéricas

Generación de máscaras dinámicas a partir del bit de inicio y longitud:


#define BITSTART_X  0
#define NBITS_X     3
#define MASK_X      (((1 << (BITSTART_X + NBITS_X)) - 1) & ~((1 << BITSTART_X) - 1))

#define BITSTART_Y  3
#define NBITS_Y     1
#define MASK_Y      (((1 << (BITSTART_Y + NBITS_Y)) - 1) & ~((1 << BITSTART_Y) - 1))

#define BITSTART_Z  4
#define NBITS_Z     2
#define MASK_Z      (((1 << (BITSTART_Z + NBITS_Z)) - 1) & ~((1 << BITSTART_Z) - 1))

// Extracción parametrizada usando las macros
vz = (v & MASK_Z) >> BITSTART_Z;

Resumen del Tema

  1. Las operaciones bit a bit permiten controlar de forma precisa dispositivos periféricos e E/S digitales.
  2. Usar | para poner a 1, & ~ para poner a 0 y ^ para cambiar el estado de un bit.
  3. Los desplazamientos << y >> alinean y extraen campos empaquetados.
  4. La notación Hexadecimal (0x) simplifica la lectura de patrones binarios dividiendo en nibbles de 4 bits.
